
# Computer Network Simulation 

A network architecture simulation designed to connect two distinct branches, focusing on capacity, security, and dynamic network management. 

## Project Overview
This project simulates a network environment utilizing Cisco Packet Tracer. The infrastructure is segmented into multiple subnets to manage bandwidth, automate IP configurations, and provide localized web services.

## Technologies & Protocols Used
- **Simulation Tool:** Cisco Packet Tracer
- **Operating System:** Cisco IOS (Command Line Interface - CLI)
- **Routing & Switching:** Layer 3 IP Routing, Layer 2 Switching
- **Protocols & Services:** DHCP, HTTP, ARP, ICMP (Ping)
- **Concepts:** OSI Model, Network Segmentation, Subnetting

##  Key Features & Implementation
* **Network Segmentation:** divided the infrastructure in differents  subnets using a Cisco router, improving the broadcast and the bandwidth.
* **Automated IP Management:** configured a DHCP server for IP address management, removing IP conflicts  and reducing network overhead.
* **Application Services:** configured a local Web server (HTTP), doing an end-to-end connection and package routing through network testing (ping and ARP tables).
* **Verification & Diagnostics:** Used Simulation Mode to inspect Protocol Data Units (PDUs) across the OSI Model layers.
